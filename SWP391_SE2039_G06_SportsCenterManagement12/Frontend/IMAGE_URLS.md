## 6. Hướng Dẫn Sử Dụng Trong Dự Án

### Trong tệp Markdown (`.md`):
```markdown
![Mô tả ảnh](https://images.unsplash.com/photo-1519315901367-f34ff9154487?q=80&w=1200&auto=format&fit=crop)
```

### Trong mã nguồn React / JSX:
```jsx
<img 
  src="https://images.unsplash.com/photo-1519315901367-f34ff9154487?q=80&w=1200&auto=format&fit=crop" 
  alt="Bể bơi tiêu chuẩn SCMS"
  loading="lazy"
  className="w-full h-64 object-cover rounded-xl"
/>
```

### Tùy chỉnh kích thước ảnh qua tham số URL Unsplash:
- Chiều rộng `1200px`: `&w=1200`
- Chiều rộng `800px`: `&w=800`
- Thumbnail `300px`: `&w=300`
- Chất lượng: `&q=80` (sắc nét) hoặc `&q=75` (tối ưu tốc độ tải)
